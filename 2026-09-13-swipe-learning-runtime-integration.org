* 2. Identity and wire ownership

=struct glide_match= exposes the exact unsigned 64-bit score already computed
by =glide.c=; learning never rescores or reorders.  Generated dictionary output
contains its stable source SHA-256 and the decoder exposes =geometry-v1=.  At
process start =main.c= performs one 128-bit =getrandom(..., GRND_NONBLOCK)=
read.  Error, =EAGAIN=, or short read closes learning without retry.  It
allocates gesture IDs monotonically from 1 before each qualified glide is
serialized; overflow permanently closes learning.

The immutable EmacsOS commit/blob named below is the sole wire-schema and
privacy authority.  wvkbd owns only production of the keyboard-observed fields
and their semantic timing.  A gesture provides session/gesture ID, algorithm
and dictionary IDs, trace/points/geometry/key height, up to three exact ranked
words/scores, and =top-queued= or =no-candidate=.  Local pre-emission rejection
is dropped.  If gesture send fails, the episode is not armed and no orphan
resolution is sent.

* 3. Owner-provided semantic seam

The candidate owner exposes one optional observer and calls it while it still
owns the state required by each payload:

1. after top word and separator requests are queued, provide the exact gesture,
   geometry, candidates, scores, and =top-queued= boundary;
2. after rank-two/three replacement requests are queued, provide selected rank;
   after rank-one replacement or blank-cell dismissal retaining the top unit,
   provide top-committed before later input;
3. after exact-unit Backspace retraction, mark correction pending.  Before the
   next qualified glide gesture send, resolve the old identity
   =retracted-then-reswiped=.  Before the next non-glide text action, resolve it
   =manual-correction-ambiguous= without that text;
4. do not resolve on Shift or another action whose existing follow-up
   disposition leaves retraction armed.  Resolve top-committed only when that
   disposition actually disarms the unit without retracting;
5. after a qualified zero-result decode, send =no-candidate= before opening the
   capture-only candidate surface.  Open it only when that datagram succeeds;
   otherwise use unchanged capture-off question-mark feedback.  The surface is
   two equal-width cells spanning the full top row, left =Misswipe= and right
   =Missing=, using the
   existing candidate strip's touch/pointer ownership and release rules.  They
   resolve explicit user-misswipe and lookup-failure respectively.  An input
   beginning outside both cells closes the surface without attribution and
   continues through ordinary dispatch, including existing Shift/follow-up
   behavior.  Capture-off keeps the current question-mark feedback; and
6. lifecycle loss clears observer state without inventing a resolution.

Old resolution send is attempted before a new gesture send.  Observer calls
carry stable gesture identity and rank explicitly and occur before candidate
state resets, so =main.c= never reconstructs consumed state.  Learning does not
own a second suggestion touch state machine and never receives manually typed
or surrounding application text.
